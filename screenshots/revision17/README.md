# V17 — rendering, walking and scenery repairs

The scenery captures precede the bear gait change. The final walking captures show the updated bear.

The scenery before/after pairs show complete foliage, matching sidewalk furniture scale and removal of overlapping benches. The cover scene uses an actual frightened civilian behind the repaired planting.

The final bear board and front/back weight boards use the production renderer, with intermediate walking weights as well as full strides. They are enlarged comparisons; actual-game captures document ordinary game scale separately.

Performance evidence starts after residents have left their initial resting poses. It records actual walking actor counts, frame-time distributions, drawing work, normalized travel and cache bounds. Initial-resting-only measurements from V16 did not capture the sustained walking cost.

The original baby artwork and NPC identities are retained. Phone checks use Chromium viewport/touch emulation; physical device performance is not established by those measurements.
