# V14 neighbourhood cast

Six fictional young adults, drawn around ages 18–24, wear the six streetwear looks retained from V13. They have distinct complexions, facial features, hair textures and hairstyles. Three older neighbours include two Middle Eastern-inspired dad characters and a middle-aged woman in casual autumn clothes.

`cast-lineup.png` shows all nine production-rendered designs. `cast-portraits.png` provides a labelled face/shoulder detail view; its portrait framing is only for reviewing the artwork. `cast-review.png` and `cast-walk-phases.png` show matching identities/outfits through walking, reactions, falling, defeat and whole-body healthy/damaged screen impact. Street/phone/impact screenshots use actual gameplay.

The JSON evidence records age-group metadata, observed source draws, complete body coverage, connected walking, stable NPC identities and actual keyboard/touch controls. Appearance changes do not change NPC behaviour. Phone checks use Chromium viewport/touch emulation.
